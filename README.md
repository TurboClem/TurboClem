## **Some Projects**

🔬 **Plasma Blob Detection** ("[`codalab_tokam2d`](https://github.com/TurboClem/codalab_tokam2d)")\
Bounding box prediction on plasma imaging data to detect and localize blobs : applying computer vision to fusion research on constrained dataset.

⚗️ **Optimal Transport Tutorial** ("[`constrained_sinkhorn_ott`](https://github.com/TurboClem/ott/blob/tutorial/constrained-sinkhorn/docs/tutorials/constrained_sinkhorn_ott.ipynb)")\
A hands-on tutorial for the [`ott-jax`](https://github.com/ott-jax/ott) library by Marco Cuturi about a Sinkhorn-type algorithm for constrained optimal transport problems. Covering core concepts and practical usage of optimal transport in JAX.

🔐 **Federated Learning Research** ("[`Federated-Learning-Research`](https://github.com/AntoineGilsonGH/Federated-Learning-Research)")\
Implementing and evaluating state-of-the-art Byzantine attacks and defenses in a federated learning setting — where robustness meets distributed ML.

🛡️ **Adversarial Examples** ("[`Adversarial_examples`](https://github.com/TurboClem/Adversarial_examples)")\
Studying adversarial robustness of image classification models : crafting and defending against imperceptible perturbations that fool neural networks.

🧬 **Graph & NLP — Molecular Description Generation** ("[`Molecular-Graph-Captioning`](https://github.com/MaxCoppa/Molecular-Graph-Captioning)")\
Translating 2D atomic structures (molecular graphs) into human-readable chemical descriptions, bridging graph neural networks and natural language generation.

🖼️ **CLIP Few-Shot Classification** ("[`CLIP-Few-Shot`](https://github.com/TurboClem/CLIP-Few-Shot/blob/main/LabCLIPFewShot_student.ipynb)")\
Exploring OpenAI's CLIP model for few-shot image classification — leveraging vision-language pretraining to generalize across visual categories with minimal labeled data.

🎵 **Music Genre Prediction**  ("[`Python-pour-la-Data-Science`](https://github.com/TurboClem/Python-pour-la-Data-Science)")\
Using Random Forest & XGBoost with Spotify’s API data to classify music genres (because data can groove too!)

📚 **Hi!ckathon**  ("[`Hickathon_2025`](https://github.com/TurboClem/Hickathon_2025)")\
Leveraging LightGBM model to predict Math Scores of student using PISA dataset.

🎭 **Generate Theater** ("[`Generate-Theater`](https://github.com/TurboClem/Generate-Theater)")\
Training a character-level language model on a Shakespeare text dataset, as a short introduction to LLMs.

📦 **Delivery Network Optimization**  ("[`ensae-prog23`](https://github.com/TurboClem/ensae-prog23)")\
Implementing Kruskal’s, Floyd-Warshall, and greedy algorithms to optimize logistics : efficiency meets algorithm design.

📊 **Interactive Data Visualization Dashboard**  ("Stock-Price-Dashboard")\
Building a Streamlit app for exploratory data analysis.
